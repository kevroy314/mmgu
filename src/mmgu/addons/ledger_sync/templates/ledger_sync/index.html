The companion script reads the game's Ledger files on your computer. The Monsters & Memories user agreement forbids software that reads or mines information the game produces, so running it is likely against the current rules and could put your account at risk. It only reads those files: it never touches game memory, network traffic, or changes any game file. Whether to run it is your own decision.

Set up the companion

  1. Install Python 3.10 or newer for Windows (tick “Add Python to PATH”).
  2. Download ledger_sync.py from the companion folder of Hallkeeper and put it in its own folder, e.g. Documents\Hallkeeper.
  3. Create an API token on your profile page and copy it.
  4. Open a Command Prompt in that folder and run:
    python ledger_sync.py --setup
    Enter the hall address {{ hall_url }} and your token.
  5. Check what it would send: python ledger_sync.py --dry-run
  6. Send it: python ledger_sync.py --once --i-understand, or keep it running while you play with --watch.

What happens to the data

  • Loot of items already in the Archive becomes a drop report (source “ledger”). Items the Archive doesn't know become suggestions for someone to review.
  • Kills {% if watch_on %}of creatures the Watch tracks update their spawn timers.{% else %}are counted but not used, because the Watch (spawn timers) is closed.{% endif %}
  • Vendor sales and harvesting are counted and otherwise ignored for now.
  • Sending the same events twice does nothing: each one is only imported once.
