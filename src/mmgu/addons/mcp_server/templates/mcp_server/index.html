1. Get a token and the tool

  1. {% if can_token %}Create an API token on your profile page (name it “Claude”) and copy it. It's shown once.{% else %}Ask an officer for a rank that can create API tokens; your current rank can't.{% endif %}
  2. Install uv. It fetches and runs the Hallkeeper MCP server for you, so there's nothing else to install.

2a. Claude Code

Run this once in a terminal, with your token pasted in:

claude mcp add hallkeeper \
  -e MMGU_API_URL={{ hall_url }} \
  -e MMGU_API_TOKEN=mmgu_your_token_here \
  -- uvx --from "mmgu[mcp] @ git+https://github.com/kevroy314/mmgu" mmgu mcp

Already have Hallkeeper installed (pip install "mmgu[mcp]")? Use -- mmgu mcp at the end instead.

2b. Claude Desktop

Settings → Developer → Edit Config, and add this to claude_desktop_config.json, then restart Claude Desktop:

{
  "mcpServers": {
    "hallkeeper": {
      "command": "uvx",
      "args": ["--from", "mmgu[mcp] @ git+https://github.com/kevroy314/mmgu", "mmgu", "mcp"],
      "env": {
        "MMGU_API_URL": "{{ hall_url }}",
        "MMGU_API_TOKEN": "mmgu_your_token_here"
      }
    }
  }
}

What Claude can do

  • Look up items and drops, the roster, the guild bank and its requests, Notice Board listings and requests, who can craft what, upcoming events and spawn timers.
  • Do what you could do yourself: report a drop, post a Notice Board request, report a time of death. It acts as you and the audit log says so.
  • Suggest anything else: other changes become suggestions an officer approves or discards. Claude can't change them directly.
{{ icon("key", 16) }} Your token, your permissions

Claude talks to the hall through the same API as the web app, using your token, so it sees exactly what you can see. Revoke the token on your profile page to cut it off. Questions you ask go to Anthropic along with what the hall returns, like anything else you share with Claude.
