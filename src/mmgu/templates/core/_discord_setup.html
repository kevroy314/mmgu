{{ icon("discord", 18) }} Connect the Discord bot

{% if has_token %}
A bot token is set, but the bot isn't connected.

Check the hall's logs (docker compose logs hallkeeper). Usual causes: the token was reset in Discord, or Server Members Intent is off.

{% else %}

The web hall works without it. The bot adds slash commands (/item, /wts, /tod…), the right-click "Catalog item" action and channel posts.

{% endif %}
  1. Open the Discord Developer Portal → New Application. Name it after your hall.
  2. Bot tab → Reset Token. Copy it. Turn on Server Members Intent.
  3. OAuth2 tab → copy the Client ID. To also offer "Log in with Discord", copy the Client Secret and add this redirect: {{ s.base_url.rstrip('/') }}/auth/discord/callback
  4. In Discord, turn on Developer Mode (User Settings → Advanced), right-click your server → Copy Server ID.
  5. Add these to the hall's .env file: 
    MMGU_DISCORD_TOKEN=your bot token
MMGU_DISCORD_CLIENT_ID=client id
MMGU_DISCORD_GUILD_ID=server id
# optional: Discord login and role sync
MMGU_DISCORD_CLIENT_SECRET=
MMGU_DISCORD_ROLE_MAP=<role id>=officer,<role id>=member
    {% if "discord" not in s.auth_mode_list %}For Discord login, also add discord to MMGU_AUTH_MODES (currently {{ s.auth_modes }}).{% endif %}
  6. Restart the hall: docker compose up -d.
  7. Invite the bot to your server: {% if s.discord_client_id %} Invite the bot {% else %} the invite link appears here once the Client ID is set. {% endif %}
  8. Pick channels for discoveries, board posts, bank requests, events and spawn alerts in Settings & channels.

Full guide: docs/discord.md in the repository. Only leaders see this badge, and it disappears once the bot is online.

{% endif %}
